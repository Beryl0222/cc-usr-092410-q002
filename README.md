# 医学教学数据沙箱

按课程目的提供限时数据切片，控制导出披露并保留分析环境谱系。

- `domain.py`：领域规则。六类记录分账（课程案例 / 临床数据快照 / 数据使用同意 /
  脱敏策略 / 分析环境 / 作业产物），限时脱敏切片、导出披露检查（含小样本阻断）、
  同意撤回即时生效、勘误与工具升级前向影响、评分时冻结环境指纹、教师复现与
  患者身份隔离、跨校到期收权、结论四要素溯源（数据范围 / 处理步骤 / 课程授权 /
  教师复核）。
- `service.py`：健康检查 HTTP 入口。
- `fixtures/domain.json`：统一领域名词与状态词汇；
  `fixtures/seed.json`：同一病例进入本校与跨校两门课程、快照两版、工具两版、
  中途撤回同意的联调场景（数据均为虚构）。
- `DESIGN.md`：治理规则到代码的映射说明。

## 运行

```bash
python3 service.py --check     # 基础配置检查
python3 domain.py --check      # 装载种子夹具并核对六账与跨课程关系
npm test                       # 运行服务契约与领域契约（共 30+ 项）
```

## 测试与构建

测试命令：

```bash
python3 -m unittest discover -s . -p 'test_*.py' && npm test
```

编译或构建命令：

```bash
python3 -m compileall -q .
```

这些命令可在单个 Linux 应用容器内执行，不需要另行启动外部服务。
